PromQL patterns

Goal Query
Request rate sum(rate(http_requests_total[5m])) by (service)
Error ratio sum(rate(http_requests_total{code=~"5.."}[5m])) / sum(rate(http_requests_total[5m]))
p99 latency histogram_quantile(0.99, sum(rate(http_request_duration_seconds_bucket[5m])) by (le))
Series count count({__name__=~".+"})

Watch out for

Warning

Never use rate on a gauge, because it hides a value that is high but steady.

Warning

A high cardinality label such as a user id creates millions of series and can crash Prometheus.

Warning

Alerts on raw CPU wake people for problems users never feel, so page on burn rate.

Warning

Head sampling drops the failures you most want to see, so use tail sampling for errors.
