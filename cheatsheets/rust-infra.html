Watch out for

Warning

Do not block inside async code, because one blocked worker delays many tasks.

Warning

unwrap in a service turns a recoverable error into a crash, so return an error instead.

Warning

Holding a lock across an await can deadlock the runtime.

Warning

Release builds differ from debug builds, so test the release binary.
