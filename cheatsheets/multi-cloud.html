Handy commands

aws sts get-caller-identity
az account show
aws ec2 describe-vpcs --query 'Vpcs[].CidrBlock'
az network vnet list --query '[].addressSpace.addressPrefixes'
aws ec2 describe-transit-gateways --query 'TransitGateways[].TransitGatewayId'
az network vnet peering list --resource-group RG --vnet-name VNET

Watch out for

Warning

Overlapping address ranges cannot be peered or routed later without renumbering.

Warning

Wildcard federation subjects let any workload assume the role.

Warning

Private endpoints need private DNS linked to every network that calls them.

Warning

A failover that was never rehearsed is a guess, so run a game day each quarter.
