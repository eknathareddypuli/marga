"Linux internals in depth" cheat sheet

"cgroup files, kernel checks and container restriction inspection."

In the print dialog, choose "Save as PDF" as the destination.

cgroup v2 files

File Meaning
cpu.max Quota and period
cpu.stat Throttling counters
memory.max Hard memory limit
memory.events high, max and oom_kill counts
memory.pressure Waiting time for memory

Quick checks

Question Command
Is a cgroup throttled? cat /sys/fs/cgroup/PATH/cpu.stat
Is memory under pressure? cat /proc/pressure/memory
Where do interrupts go? cat /proc/interrupts
Which NUMA node holds memory? numastat -p PID
Disk waiting? iostat -x 1
Conntrack use cat /proc/sys/net/netfilter/nf_conntrack_count

Container restrictions

Layer Inspect
Namespaces ls -l /proc/PID/ns
Capabilities grep Cap /proc/PID/status
seccomp grep Seccomp /proc/PID/status
Root file system `mount

Watch out for

Warning

Raising a CPU limit hides throttling only if the thread count also fits the quota.

Warning

Free memory is the wrong alert, because Linux uses spare memory as cache on purpose.

Warning

Transparent huge pages can cause latency stalls in databases, so follow the vendor advice.

Warning

Privileged containers receive nearly every capability, so add only the ones you need.
